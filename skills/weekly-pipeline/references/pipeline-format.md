# Weekly pipeline format

```
Pipeline as of <as_of>: <open_deals> open deals

By stage
- Lead: <n>
- Touring: <n>
- Proposal sent: <n>
- LOI signed: <n>
- Lease negotiation: <n>
- Closed won / Closed lost: <n> / <n>

Needs attention (no activity for 21+ days)
- <deal name> (<stage>, <owner>): <days_since_activity> days. Suggested next step: <one line>

Moving
- <open deals with activity in the last 7 days, one line each>
```

If nothing is stale, write "Nothing stale this week." Use the stage names exactly as the CRM
returns them.
